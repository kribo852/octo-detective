# I'll be glad if you would like to contribute, here are som areas where that can be done:

## Documentation
If you lack something in the documentation, put an issue on it, and we'll see what to do about it, or make a pull request.

## Features
Suggest an improvement in the discussion or as a Issue

## Graphics and art, or sound effects
If you would like to improve the art or graphics, add the change suggested in a Issue. The same goes if you have a sound effect you think would be neat.

## Bugs
Report bugs, or unexpected behaviour in a issue.

## Maps/levels
It would be cool if someone tried to make a new level, make a pull request if you think that you have made a cool level. The levels are placed in the levels folder and have a Lua syntax, you can check the other levels to get some examples.
